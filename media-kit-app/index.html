Google / YouTube API application information

Paplovag Creator Media Kits

Private analytics automation used by the owner of Paplovag Gaming and Tűzpróba to keep creator media-kit statistics up to date.

What the application does

The application connects the owner's YouTube channels using Google OAuth and reads channel and aggregated performance data. It updates private, password-protected media kits for Paplovag Gaming and Tűzpróba.

Permissions

Only read-only YouTube permissions are requested: youtube.readonly and yt-analytics.readonly. The application does not upload videos, edit channel settings, post comments or perform other write actions on the connected YouTube accounts.

Who uses it

This is a personal-use application for the creator/channel owner. Media-kit visitors only see selected aggregated statistics and cannot access the connected Google account.

Data handling

OAuth tokens are handled server-side and stored encrypted. Aggregated analytics snapshots may be stored in Cloudflare KV to power the media-kit pages and scheduled daily refreshes.
