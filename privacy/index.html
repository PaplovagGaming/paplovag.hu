Privacy Policy

Tűzpróba Media Kit

This Privacy Policy explains how the Tűzpróba Media Kit application accesses, uses, stores and shares Google user data when connecting to YouTube and YouTube Analytics.

Effective date: September 9, 2026

1. Application and purpose

The Tűzpróba Media Kit is a private creator analytics tool operated by Paplovag / Tűzpróba. It is used to automatically update channel-performance and audience statistics displayed in the Tűzpróba creator media kit.

The application is intended for the channel owner's own use. It does not provide public account-management features and does not allow third parties to modify the connected YouTube account.

2. Google user data we access

The application requests only read-only Google OAuth permissions required for its stated purpose:

  • youtube.readonly — to read basic YouTube account, channel and video information.
  • yt-analytics.readonly — to read YouTube Analytics reports for the connected channel.

Depending on availability from the YouTube APIs, this may include channel identifiers, public video metadata, subscriber and view statistics, watch-time and performance metrics, and aggregated audience or geographic analytics.

3. How we use Google user data

Google user data is used solely to calculate and display Tűzpróba creator-media-kit statistics and to keep those statistics up to date. The application does not use Google user data for advertising, profiling unrelated to the media kit, credit decisions, or sale to third parties.

4. Storage and security

OAuth credentials and tokens are handled server-side and are not intentionally exposed in the public browser client. Application secrets are stored using the hosting platform's protected environment-secret functionality. Aggregated media-kit statistics may be cached or stored in Cloudflare KV so the media kit can load quickly without requesting YouTube Analytics data on every page view.

Access is limited to the minimum data and permissions required to operate the feature. Reasonable technical measures are used to protect stored credentials and application data.

5. Sharing of data

Google user data is not sold. It is not shared with advertisers or data brokers. Data may be processed by infrastructure providers only as necessary to operate the service, including Google for API access and Cloudflare for hosting, secrets and KV storage.

6. Data retention

OAuth tokens and cached analytics data are retained only while they are needed to operate the Tűzpróba Media Kit or until access is revoked. Cached or stored analytics snapshots may be replaced by newer values as the media kit updates.

7. Revoking access and deletion

The connected Google account can revoke the application's access at any time from the Google Account security and third-party access settings. After access is revoked, the application can no longer request new YouTube or YouTube Analytics data for that account.

Requests to remove stored application data related to the connection can be sent to paplovaggaming@gmail.com.

8. Limited use

The Tűzpróba Media Kit's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

9. Changes to this policy

This Privacy Policy may be updated if the application's functionality, requested permissions, storage practices or applicable requirements change. The effective date at the top of this page will be updated when material changes are made.

10. Contact

Questions about this Privacy Policy or the Tűzpróba Media Kit can be sent to paplovaggaming@gmail.com.
