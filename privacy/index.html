Privacy Policy

Paplovag Creator Media Kits

This Privacy Policy explains how the private Paplovag creator-media-kit analytics tools access, use, store and share Google user data when connecting Paplovag Gaming or Tűzpróba to YouTube and YouTube Analytics.

Effective date: September 10, 2026

1. Applications and purpose

The Paplovag Gaming Media Kit and Tűzpróba Media Kit are private creator analytics tools operated by Paplovag. They automatically update channel-performance and audience statistics displayed in the corresponding creator media kits.

The tools are intended for the channel owner's own use. They do not provide public YouTube account-management features and do not allow media-kit visitors to modify a connected YouTube account.

2. Google user data we access

The applications request only read-only Google OAuth permissions required for their stated purpose:

  • youtube.readonly — to read basic YouTube account, channel and video information.
  • yt-analytics.readonly — to read YouTube Analytics and supported YouTube Reporting data for the connected channel.

Depending on API availability, this may include channel identifiers, public video metadata, subscriber and view statistics, watch-time and performance metrics, impressions, click-through rates, and aggregated audience or geographic analytics.

3. How we use Google user data

Google user data is used solely to calculate, maintain and display creator-media-kit statistics for the connected Paplovag Gaming or Tűzpróba channel. It is not used for unrelated advertising profiles, credit decisions or sale to third parties.

4. Storage and security

OAuth credentials and refresh tokens are handled server-side. Refresh tokens are stored encrypted in the application's Cloudflare KV storage; application secrets are stored using protected environment-secret functionality. Aggregated analytics and reporting snapshots may also be stored in Cloudflare KV so the media kits do not need to request Google data on every page view.

Each channel uses a separate stored OAuth token, media-kit data record and reach-reporting history.

5. Sharing of data

Google user data is not sold and is not shared with advertisers or data brokers. Data may be processed by infrastructure providers only as necessary to operate the service, including Google for API access and Cloudflare for hosting, secrets and KV storage.

6. Data retention

OAuth tokens and cached analytics data are retained only while required to operate the media kits or until access is revoked or the stored connection is removed. Analytics snapshots are replaced or updated as newer values become available.

7. Revoking access and deletion

The connected Google account can revoke application access at any time from Google Account security and third-party access settings. After revocation, the applications can no longer request new YouTube or YouTube Analytics data for that connection.

Requests to remove stored application data can be sent to paplovaggaming@gmail.com.

8. Limited Use

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

9. Changes to this policy

This policy may be updated if functionality, requested permissions, storage practices or applicable requirements change. The effective date above will be updated for material changes.

10. Contact

Questions about this Privacy Policy or the Paplovag creator media-kit tools can be sent to paplovaggaming@gmail.com.
