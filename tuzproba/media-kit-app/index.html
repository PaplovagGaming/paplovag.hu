Tűzpróba Media Kit

A private creator analytics integration used to keep the Tűzpróba media kit up to date with YouTube and YouTube Analytics data.

What the application does

The Tűzpróba Media Kit connects the channel owner's Google / YouTube account to a private server-side analytics workflow. It automatically reads selected channel-performance and audience metrics and uses them to update the creator media kit.

Permissions requested

  • YouTube read-only access for channel and video information.
  • YouTube Analytics read-only access for channel analytics reports.

The application does not request permission to upload, edit or delete videos, post comments, or otherwise modify the connected YouTube account.

Who uses it

This application is intended for the Tűzpróba channel owner's own use. It is not a public SaaS product and does not offer Google account access to unrelated users.

Data practices

Google user data is used only for the media kit and related creator analytics. For details about access, storage, sharing, retention and revocation, see the Privacy Policy.
